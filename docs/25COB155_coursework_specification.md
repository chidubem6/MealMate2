# 25COB155 Mobile Application Development — Coursework Specification

> This coursework represents **100%** of the total assessment of the module.

---

## The Task — Native Android Application Development

For this project, you will develop a native Android Application using Android Studio from scratch. The app functionalities are implemented in Kotlin language using native Android APIs and libraries introduced in the lectures.[^1]

Students will work individually. Each student is required to propose an app, specify its functionalities, design and develop the app, and reflect on what has been done.

---

## Propose and Specify an App

You will need to:

- Propose a mobile application of suitable complexity, specify what problem the app solves, its functionalities, and highlight how it would meet the technical requirements.
- Design mock screens for all user-facing screens. Hand-drawn sketches are OK, but they must be in a digital format.

Individual formative feedback on the app proposal is available during the lab sessions and weekly office hour. Each student is allowed to ask for feedback once before the final submission.

---

## Develop the App (70%)

- Develop your application, applying the Mobile App Development best practice and Mobile App Security knowledge introduced in the module and identified in your own research **(15%)**.
- Make sure your application meets the technical requirements listed below.

### Mandatory Requirements (25%)

Your application should:

- Have a minimum of two distinct screens.
- Use the navigation component to move between screens in your app.
- Use Intent to move to an outside app.
- Work properly with the app lifecycle (including rotate screen changes).
- Use permissions and use them responsibly.
- Make use of local storage.
- Create your own ContentProvider and create instrumented tests for it.

### Optional Features — Select 3 from the Following (15%)

Your application should also include **three** of the following:

- Use Firebase for storing and retrieving data
- Receive Broadcast events and make use of them in meaningful ways
- Implement Android ShareSheet
- Implement an AI feature
- Use Notifications
- Adapt your app for different screen sizes
- Capture touch gestures and make reasonable use of them

> **Note:** Choose three options that apply the most to your app idea. Implementing more than three will **not** result in more marks.

### Code Quality (15%)

The remaining 15% of marks are awarded on:

- Code style
- Readability
- App complexity
- App usability

---

## Demo (30%)

Each student is required to record a video demo (**15 minutes maximum**) including:

- A brief introduction to the app proposal and design
- A demo of the app functionalities
- An overview of program implementation
- Reflective comments on mobile app development best practice and mobile app security

Marks for the demo will be awarded for completeness, suitability and quality of design, accurate and clear explanation, evidence-based argument and critical thinking.

Panopto is provided for students to record and edit videos. You can use other video recording and editing software if you prefer. All demos should be uploaded through Panopto to bypass the file size limit on Learn, and also submitted in the online text part of the Learn submission.

Student guide: [Recording videos using Panopto](https://learn.lboro.ac.uk/ludata/tel/Student_resources/recording_videos_using_panopto/#/)
